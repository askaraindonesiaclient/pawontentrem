# Panduan Pengguna Admin — Pawon Tentrem

Panduan ini ditujukan bagi pemilik usaha dan staf dapur Pawon Tentrem untuk mengelola sajian harian melalui dashboard web.

---

## 🌅 1. Rutinitas Membuka Hari

1. Buka peramban pada ponsel atau komputer dan kunjungi `/admin/login`.
2. Masukkan alamat email dan kata sandi akun pengelola Anda.
3. Pada halaman utama dashboard, perhatikan tanggal hari ini (Zona Waktu: WIB).
4. Tekan tombol besar hijau **+ Tambah Menu Hari Ini**.
5. Jika menu hari ini hampir sama dengan kemarin, Anda dapat memilih tombol **Salin dari Tanggal Lain** untuk menyalin daftar sajian tanpa perlu mengetik ulang dari awal.

---

## 📸 2. Menambah Menu dengan Foto & Ponsel

1. Pada halaman tambah menu, tekan tombol **Ambil Foto** untuk mengaktifkan kamera ponsel langsung, atau **Pilih dari Galeri** jika foto sudah tersimpan di galeri.
2. Sistem akan otomatis menampilkan pratinjau foto dalam rasio **4:3**.
3. Ketik **Nama Menu** (misalnya: *Ayam Goreng Lengkuas*). Field ini wajib diisi.
4. **Harga Bersifat Opsional**:
   - Jika Anda tidak mengisi harga, sistem tidak akan menampilkan `Rp0` atau tanda strip. Tampilan akan tetap rapi tanpa kolom harga kosong.
   - Jika Anda ingin menampilkan harga, buka menu *Detail Tambahan*, isi angka harga (misal: `18000`), dan pilih satuan (*per potong*, *per porsi*, dsb).
5. Tekan tombol hijau **Simpan & Tambah Lagi** untuk langsung melanjutkan ke menu berikutnya, atau **Simpan Draf** jika sudah selesai.

---

## 🚀 3. Mempratinjau & Menerbitkan Menu

1. Perubahan menu yang Anda masukkan tersimpan dengan aman sebagai **Draf**. Pengunjung di halaman depan belum dapat melihat draf ini sebelum diterbitkan.
2. Buka halaman **Menu Harian** atau tekan tombol **Pratinjau & Terbitkan**.
3. Periksa daftar sajian, urutan masakan, dan foto.
4. Tekan tombol **Terbitkan Menu Hari Ini**.
5. Dalam satu detik, sistem akan memperbarui tampilan beranda secara atomik (*keseluruhan menu tayang serentak tanpa pengunjung melihat menu terpotong*).

---

## 🍲 4. Menandai Lauk yang Habis

1. Jika lauk tertentu habis sebelum warung tutup:
2. Buka menu **Menu Harian** di dashboard.
3. Klik tombol status di samping nama masakan tersebut hingga berubah menjadi **Habis hari ini**.
4. Tekan **Pratinjau & Terbitkan**.
5. Di beranda pengunjung, menu tersebut akan diberi label *Habis hari ini*, dan foto makanan tersebut tidak akan berputar lagi di slideshow promosi.

---

## 🌙 5. Mengakhiri Hari Layanan

- Anda **tidak perlu repot menghapus** menu lama saat menutup rumah makan di malam hari.
- Tepat pukul 00.00 WIB tengah malam, sistem secara otomatis beralih ke hari layanan baru. Menu hari kemarin akan tersimpan secara otomatis di menu **Riwayat** dan tidak akan diklaim sebagai menu hari ini.
